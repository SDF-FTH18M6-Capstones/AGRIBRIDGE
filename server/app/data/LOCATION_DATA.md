# Kenya location reference

Source: https://github.com/davidamunga/kenya-locations/tree/main/data
Downloaded 2026-11-24. Data: CC BY 4.0 https://creativecommons.org/licenses/by/4.0/
Attribution: kenya-locations / David Amunga, IEBC, KNBS; administrative subcounties and ward links from HDX / American Red Cross.

47 counties, 302 administrative subcounties, 1,450 wards. This is a third-party reference, not a current gazetted register or a boundary-validation service. Subcounty data dates to 2016–2020; 104 ward links use approximate matching/inference. See upstream data/meta.json and sources/hdx-kenya-wards/matches.json. Existing text is retained; never infer legacy profiles' codes. Review corrections against current local records before production use. No farm coordinates are included.
